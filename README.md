# study-math

A record of what I learn about mathematics.

The point is the record, not the studying. A worked problem is forgotten in a
week; the definition it turned on, written down once, is not. So each note is
kept short enough to reread, and long enough to rebuild the idea from.

## Layout

- [`INDEX.md`](INDEX.md) — one line per note. Scan this first.
- `notes/<area>/<topic>.md` — the notes themselves, one idea per file.

Areas are created as they are needed: `algebra`, `analysis`, `calculus`,
`discrete`, `geometry`, `linear-algebra`, `number-theory`, `probability`,
`statistics`.

## Note format

Front matter, then short sections — definition, key facts, an example, the
mistakes worth remembering. Sections that have nothing to say are left out.
Notation is LaTeX between `$…$` or in `$$…$$` blocks, which GitHub renders.

## What is not kept

No solution dumps, no copied textbook chapters, no per-session logs. A note is
added when the idea is new; when it is not, the existing note is sharpened
instead. The index stays readable end to end, which is the only property that
makes any of this useful.
